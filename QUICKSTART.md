# Быстрый старт Focus ADHD-планера

## ✅ Что уже реализовано

### Backend (API)
- ✅ Аутентификация (JWT + refresh tokens)
- ✅ CRUD задач с подзадачами
- ✅ Повторяющиеся задачи (RRULE)
- ✅ Push-уведомления через BullMQ + Expo

### Mobile (React Native + Expo)
- ✅ Авторизация (login/register)
- ✅ Экран таймлайна (today) с полной интеграцией API
- ✅ Создание/редактирование задач (task-form)
- ✅ Настройки с выходом
- ✅ Компоненты Timeline, TaskBlock, NowIndicator
- ✅ Оптимистичные обновления для быстрого отклика

## 🚀 Запуск проекта

### 1. Установка зависимостей

```powershell
# Корневая директория
cd D:\ADHD\ADHD
npm install

# Мобильное приложение
cd apps\mobile
npm install
```

### 2. Запуск инфраструктуры (PostgreSQL + Redis)

```powershell
# В корне проекта
docker compose up -d

# Проверка статуса
docker compose ps
```

### 3. Настройка базы данных

```powershell
cd apps\api

# Применить миграции
npx prisma migrate dev

# Генерация Prisma Client
npx prisma generate
```

### 4. Запуск Backend API

```powershell
# Из apps/api или из корня
npm run dev:api

# API будет доступен на http://localhost:3000
```

### 5. Запуск мобильного приложения

```powershell
# Из apps/mobile или из корня
npm run dev:mobile

# Expo Metro bundler запустится и покажет QR-код
```

### 6. Подключение к API

**Важно!** По умолчанию мобильное приложение пытается подключиться к `http://10.0.2.2:3000` (Android Emulator).

Для тестирования на реальном устройстве:

1. Узнайте IP вашего компьютера в локальной сети:
   ```powershell
   ipconfig
   # Найдите IPv4 адрес (например, 192.168.1.100)
   ```

2. Создайте `.env` файл в `apps/mobile/`:
   ```
   EXPO_PUBLIC_API_URL=http://192.168.1.100:3000
   ```

3. Перезапустите Metro bundler с очисткой кэша:
   ```powershell
   npx expo start -c
   ```

## 📱 Тестирование функционала

### Регистрация и вход
1. Откройте приложение
2. Нажмите "Нет аккаунта? Зарегистрироваться"
3. Выберите Email или Телефон
4. Введите данные (пароль минимум 8 символов)
5. После регистрации вы автоматически войдете

### Работа с задачами

**Быстрое создание:**
1. Нажмите FAB кнопку (+) внизу справа
2. Введите название задачи
3. Нажмите "Создать"

**Создание с деталями:**
1. Тап по фону таймлайна в нужное время
2. Введите название
3. Нажмите "Подробнее →"
4. Настройте время, длительность, цвет, повтор, подзадачи
5. Нажмите "Сохранить"

**Взаимодействие с задачами:**
- **Короткий тап** → переключить "выполнено/не выполнено" (мгновенно)
- **Долгий тап** → открыть детали для редактирования

**Особенности UX для ADHD:**
- Таймлайн автоматически прокручивается на текущее время
- Мгновенный отклик при отметке задач (оптимистичное обновление)
- Минимум обязательных полей (только название)
- Пресеты для подзадач ("Уборка комнаты" → Мусор/Пол/Поверхности)

## 🐛 Решение проблем

### API не отвечает
```powershell
# Проверьте, что контейнеры запущены
docker compose ps

# Проверьте логи API
cd apps\api
npm run start:dev
```

### Не подключается мобильное приложение
1. Убедитесь, что телефон и компьютер в одной сети
2. Проверьте `EXPO_PUBLIC_API_URL` в `.env`
3. Отключите брандмауэр Windows для порта 3000
4. Перезапустите Metro bundler с `-c`

### Ошибки Prisma
```powershell
# Пересоздайте БД и примените миграции
cd apps\api
npx prisma migrate reset
npx prisma generate
```

### Expo не запускается
```powershell
# Переустановите зависимости
cd apps\mobile
rm -rf node_modules
npm install
npx expo start -c
```

## 📚 Архитектура

```
Backend:
- NestJS модули с чистой архитектурой
- Prisma ORM для типобезопасных запросов
- BullMQ для надёжных очередей
- JWT стратегия с refresh tokens

Mobile:
- Expo Router для навигации
- Zustand для локального state
- React Query для серверного state
- SecureStore для токенов
```

## 🔐 Безопасность

- Пароли хешируются через bcrypt (12 раундов)
- JWT токены с коротким TTL (15 минут)
- Refresh tokens хранятся в SecureStore (Keychain/Keystore)
- Автоматическое обновление токенов через интерцептор
- Минимум данных в push-уведомлениях (152-ФЗ)
