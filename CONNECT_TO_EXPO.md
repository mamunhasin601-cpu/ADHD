## 🐛 Если получаете ошибку "Something went wrong"

### Возможные причины:

1. **Backend API недоступен**
   - Проверьте: `curl http://localhost:3000/auth/me`
   - Убедитесь, что API запущен

2. **Проблема с assets (иконки/изображения)**
   - Это нормально для первого запуска
   - Попробуйте нажать "Reload" в Expo Go

3. **Несовместимая версия Expo Go**
   - Обновите Expo Go в Play Store
   - Проект использует Expo SDK 51

4. **Firewall блокирует порт**
   - Разрешите Node.js в Windows Firewall
   - Порт 8081 и 3000 должны быть открыты
