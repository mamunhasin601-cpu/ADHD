# Инструкция по тестированию на Android эмуляторе

**Дата:** 29 июля 2026

---

## 📱 Ситуация

- ✅ Android Studio установлен: `C:\Program Files\Android\Android Studio`
- ✅ Android SDK установлен: `C:\Users\mihaa\AppData\Local\Android\Sdk`
- ❌ Эмуляторы Android не созданы (AVD список пуст)
- ❌ System images не установлены

---

## 🎯 Что нужно сделать

### Вариант 1: Создать эмулятор через Android Studio (Рекомендуется)

1. **Откройте Android Studio** (уже запущен)

2. **Откройте AVD Manager:**
   - Главное меню: `Tools` → `Device Manager`
   - Или кнопка на панели инструментов (иконка телефона)

3. **Создайте новое виртуальное устройство:**
   - Нажмите `Create Device`
   - Выберите устройство: **Pixel 5** (рекомендуется)
   - Нажмите `Next`

4. **Скачайте system image:**
   - Выберите **Android 13 (Tiramisu)** API Level 33
   - Если не скачан — нажмите `Download` рядом с ним
   - Дождитесь завершения загрузки
   - Нажмите `Next`

5. **Настройте AVD:**
   - Имя: `Pixel_5_API_33`
   - Startup orientation: `Portrait`
   - Нажмите `Finish`

6. **Запустите эмулятор:**
   - В списке устройств нажмите ▶️ (Play) рядом с созданным AVD
   - Дождитесь загрузки Android (1-2 минуты)

---

### Вариант 2: Тестирование на реальном Android устройстве

Если у вас есть физический телефон Android:

1. **Включите режим разработчика:**
   - `Настройки` → `О телефоне` → 7 раз тапните на `Номер сборки`

2. **Включите отладку по USB:**
   - `Настройки` → `Для разработчиков` → включите `Отладка по USB`

3. **Подключите телефон к компьютеру через USB**

4. **Проверьте подключение:**
   ```powershell
   & "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" devices
   ```
   Должно показать ваше устройство.

5. **Обновите .env для реального устройства:**
   ```env
   # apps/mobile/.env
   EXPO_PUBLIC_API_URL=http://172.18.0.1:3000
   ```

### 2. Тестовый сценарий

После запуска приложения:

#### ✅ Проверка 1: Авторизация
1. Откройте приложение
2. Нажмите "Нет аккаунта? Зарегистрироваться"
3. Или войдите с существующим:
   - Email: `test@example.com`
   - Пароль: `testpass123`
4. **Ожидается:** Переход на экран таймлайна

#### ✅ Проверка 2: Регистрация push-токена
1. После входа проверьте логи Metro Bundler
2. **Ожидается:** `Push token registered: ExponentPushToken[...]`
3. Или проверьте в БД:
   ```sql
   SELECT email, expoPushToken FROM "User" WHERE email='test@example.com';
   ```

#### ✅ Проверка 3: Таймлайн
1. Должен показаться экран с временной шкалой 6:00-24:00
2. **Ожидается:** Автоскролл на текущее время (красная линия "Сейчас")
3. Должны быть видны задачи на сегодня (если есть)

#### ✅ Проверка 4: Создание задачи
1. Нажмите FAB кнопку (+) внизу справа
2. Введите название: "Тестовая задача"
3. Нажмите "Создать"
4. **Ожидается:** Задача появится на таймлайне без времени

#### ✅ Проверка 5: Создание с временем
1. Тапните по фону таймлайна (например, на 15:00)
2. Введите название: "Встреча в 15:00"
3. Нажмите "Подробнее →"
4. Настройте длительность: 60 минут
5. Выберите цвет: любой
6. Нажмите "Сохранить"
7. **Ожидается:** Задача появится на шкале в 15:00 с полоской на 60 минут

#### ✅ Проверка 6: Toggle выполнения
1. Короткий тап по любой задаче
2. **Ожидается:** Мгновенное изменение (зачеркивание или галочка)
3. Повторный тап — отмена выполнения

#### ✅ Проверка 7: Редактирование
1. Долгий тап (long press) по задаче
2. **Ожидается:** Открывается форма редактирования
3. Измените название
4. Нажмите "Сохранить"
5. **Ожидается:** Изменения видны на таймлайне

#### ✅ Проверка 8: Фильтр по дате
Проверьте через API (эмулятор/устройство не имеет навигации по дням пока):
```bash
TOKEN="YOUR_TOKEN_FROM_LOGIN"
curl -H "Authorization: Bearer $TOKEN" "http://localhost:3000/tasks?date=2026-07-29"
```
**Ожидается:** Только задачи на 29 июля

## 🐛 Возможные проблемы

### Приложение не подключается к API

**Симптом:** Ошибки сети, "Network request failed"

**Решение:**
1. Проверьте `.env` в `apps/mobile/.env`:
   ```env
   # Для эмулятора
   EXPO_PUBLIC_API_URL=http://10.0.2.2:3000
   
   # Для реального устройства
   EXPO_PUBLIC_API_URL=http://172.18.0.1:3000
   ```

2. Перезапустите Metro с очисткой кэша:
   ```powershell
   cd apps\mobile
   npx expo start -c
   ```

### Эмулятор не запускается

**Возможные причины:**
- Не включена виртуализация в BIOS (VT-x/AMD-V)
- Hyper-V конфликтует (нужно отключить)
- Недостаточно RAM (минимум 8GB рекомендуется)

**Решение:**
1. Проверьте виртуализацию в Диспетчере задач → Производительность → CPU
2. Если Hyper-V включен:
   ```powershell
   # Запустить от администратора
   bcdedit /set hypervisorlaunchtype off
   # Перезагрузка
   ```

### Push-уведомления не регистрируются

**Симптом:** Нет лога "Push token registered"

**Проверки:**
1. Проверьте консоль на ошибки разрешений
2. На реальном устройстве — вручную дайте разрешение в настройках приложения
3. На эмуляторе — Google Play Services должны быть установлены
