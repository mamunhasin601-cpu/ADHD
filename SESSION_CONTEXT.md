## ✅ Что было сделано в этой сессии

### 1. Исправлены три критических бага

#### Баг #2: "Создать" ничего не делает (FAB quick-add)
**Проблема:** При нажатии FAB "+" → ввод названия → "Создать" задача сохранялась на backend с `startTime: null`, но `TaskBlock.tsx` содержал `if (!task.startTime) return null`, поэтому задача создавалась, но нигде не отображалась.

**Решение:** Добавлен список "Без времени" над таймлайном в `app/(tabs)/today.tsx`:
- Фильтруются задачи с `!task.startTime`
- Отображаются компактным списком с цветной точкой
- Тап → toggle "выполнено"
- Долгий тап → открыть форму редактирования

**Файлы:**
- `apps/mobile/app/(tabs)/today.tsx` — добавлен `unscheduledTasks` фильтр и UI-секция

#### Баг #3: Буква "О" обрезается в слове "Отмена"
**Проблема:** На 360dp Android-экранах три кнопки модала (`Отмена` + `Подробнее →` + `Создать`) с `justifyContent: 'flex-end'` суммарно занимали ~319px при доступных 312px (360 - 48px padding). Кнопка "Отмена" уходила за левый край и первая буква "О" обрезалась.

**Решение:** Изменён `justifyContent` с `'flex-end'` на `'space-between'` в `modalActions` — кнопки теперь распределяются по всей ширине, "Отмена" всегда начинается от левого края контента.

**Файлы:**
- `apps/mobile/app/(tabs)/today.tsx:253` — `justifyContent: 'space-between'`

#### Баг #4: Задачи с одинаковым временем накладываются слоями
**Проблема:** При совпадении времени задачи рендерились с одинаковыми `top` координатами и перекрывали друг друга.

**Решение:** Реализован алгоритм колоночной раскладки (как в Google Calendar):
- **Новый модуль** `lib/timeline-layout.ts` — функция `computeTimelineLayout()` группирует пересекающиеся по времени задачи в кластеры и назначает каждой `columnIndex` и `columnCount` жадным алгоритмом
- **Timeline.tsx** — добавлен `useMemo(() => computeTimelineLayout(tasks), [tasks])`, передаёт layout-данные каждому `TaskBlock`
- **TaskBlock.tsx** — ПОЛНОСТЬЮ ПЕРЕПИСАН: теперь использует вложенную структуру (`View` для строки + `Pressable` для блока), колонки позиционируются через **процентные строки** (`left: '${n}%'`, `width: '${w}%'`), не через `calc()` (который не поддерживается в React Native на Android/iOS)

**Файлы:**
- `apps/mobile/lib/timeline-layout.ts` — НОВЫЙ
- `apps/mobile/components/timeline/Timeline.tsx` — импорт `useMemo`, `computeTimelineLayout`, вызов и прокидка `columnIndex`/`columnCount`
- `apps/mobile/components/timeline/TaskBlock.tsx` — полная перезапись с процентной раскладкой

## 🔧 Технические детали

### React Native особенности (критично!)
- **CSS `calc()` НЕ поддерживается** на нативных платформах (Android/iOS), только на React Native Web
- Для динамических вычислений в стилях использовать:
  - Процентные строки: `'50%'`, `'33.33%'`
  - Числовые значения: `width: 100`, `left: 50`
  - НЕ использовать: `calc(100% - 20px)` — вызовет ошибку рендеринга

### Структура проекта
- Монорепозиторий: `apps/mobile`, `apps/api`, `packages/shared-types`
- Mobile: React Native + Expo SDK 51, Expo Router (file-based routing)
- Backend: NestJS + Prisma + PostgreSQL + Redis (BullMQ)
- Auth: JWT + refresh tokens, SecureStore для хранения на устройстве
