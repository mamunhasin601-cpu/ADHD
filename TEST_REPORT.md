## 🔐 Безопасность

### Реализовано
✅ **Bcrypt hashing** — 12 раундов для паролей  
✅ **JWT + Refresh tokens** — короткий TTL (15 мин) + долгий refresh (30 дней)  
✅ **SecureStore** — токены в Keychain (iOS) / Keystore (Android)  
✅ **Автообновление токенов** — интерцептор в axios  
✅ **CORS** — только для dev-режима  
✅ **Validation Pipe** — whitelist для DTO  
✅ **Минимум данных в push** — только "Пора начинать", без деталей задач


### Тестирование на реальном устройстве

1. Узнать IP компьютера:
   ```powershell
   ipconfig
   # Найти IPv4, например: 192.168.1.100
   ```

2. Создать `apps/mobile/.env`:
   ```
   EXPO_PUBLIC_API_URL=http://192.168.1.100:3000
   ```

3. Перезапустить с очисткой кэша:
   ```powershell
   cd apps\mobile
   npx expo start -c
   ```

4. Отсканировать QR-код в Expo Go
